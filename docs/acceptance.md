# OIS 验收

<a id="current-status"></a>

只验收 [OIS 范围](ois-mvp.md)。测试入口见[运行手册](runbook.md)。

- 规则：双重签署放行、计划修订、患者与机器冲突、取消恢复、版本冲突、验证失败分类、设备恢复、角色约束、中断和人工跟进。
- MySQL：并发单一成功、原子审计、幂等回放、失败回滚、完整失败→修订→放行→中断闭环。
- HTTP：登录/退出、CSRF、角色隔离、计划审核、预约冲突、版本及幂等，旧 API 返回 404，OpenAPI 只暴露 OIS 和认证。
- 浏览器：跨角色处方/计划/审核/实验排期；单次预约预览、取消恢复、日周日历。
- 升级：从清理前 OIS 数据库迁移，验证临床数据和幂等重放保留、旧表及旧账号删除，再验证备份恢复。
- 容器：全新数据库和打包前端启动，完成 HTTP 验证；打包页面测试覆盖根路径、JS/CSS 资源及旧入口 404。

规则测试用可控时钟验证完整执行闭环，浏览器测试不代表真实临床设备验收。历史混合版本的 93 项后端及 18 项浏览器测试数量不再作为当前版本证据。

## 2026-10-16 清理验证

本机已通过：18 项 .NET 测试、3 项浏览器测试、HTTP 认证及 OIS 命令验证、前端构建与格式检查、EF 模型/迁移一致性检查，以及上版 OIS 数据库升级和 SQL 备份恢复演练。测试使用独立 Compose 项目和数据库，未迁移原演示库。
