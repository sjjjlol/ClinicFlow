# ADR 006 — Pi Agent Core 与私有进程通道

按用户要求将多轮模型/工具执行交给Pi Agent Core，采用维护中的`@earendil-works/pi-agent-core` 0.87.1。现有.NET掌握身份、档案可见范围、日期计算、事务与会话；Pi通过私有stdin/stdout调用.NET的模型适配器和两个只读工具，避免增加需要鉴权的服务端口或在两个运行时复制数据库权限逻辑。模型增量同时送入Pi流和浏览器SSE；预约创建仍由独立的人工确认请求触发。

每轮独立Node进程便于取消和回收，代价是启动开销与镜像增加Node依赖。最多四轮并发，整轮90秒；断流清空不完整候选，不自动重试写入。确认结果不明时保留同一候选及幂等键核实。注册者可使用助手，但会话、目录、搜索与确认均绑定本人档案；模拟冲突接口仅供开发环境Scheduler。
