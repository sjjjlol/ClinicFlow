# ADR 005 — 个人档案绑定与预约完成

注册账号固定为Booker，并原子创建一个个人Patient档案；以不可由客户端修改的账号档案绑定作为预约可见性边界，而不是以预约创建者作为归属。因此工作人员代个人建的预约仍会出现在“我的预约”，注册者不会获得预置角色，也不能关联已有他人档案。数据库允许工作人员的PatientId为空，保持旧账号与旧预约兼容；不提供亲友代约、档案合并或角色自助修改。

Completed由Scheduler在Confirmed预约结束后显式登记，释放占用且不可撤销。它与取消的区别是“已履行”而非“未履行”；不因时间流逝自动声称预约已完成。完成沿用原有资源锁、版本、事务、幂等、审计和Outbox，接收端必须先支持新状态再部署发送端。工作人员保留历史补录和纠错能力，自助预约只允许未来时间，开始后不能自助改期或取消；营业日限制仍是AI候选搜索的范围，不是本次新增的全局规则。
